Instalar o leitor neste computador

Um pacote único com o driver, o programa e o passo a passo (LEIA-ME). Extraia o .zip e siga as pastas numeradas.

O Instalador oficial (.msi) instala só o programa de leitura (não traz o driver) — útil quando o antivírus da empresa aceita melhor um instalador.

⬇ Baixar o leitor de digital ⬇ Instalador oficial (.msi)
Ver o passo a passo da instalação

Passo 1 · Driver

  1. Baixe o pacote e extraia o .zip (botão direito, Extrair tudo).
  2. Abra a pasta 1-Instalar-driver e execute o UBio_Hamster_X_Driver_Setup_x64.exe.
  3. Siga as telas até Concluir e ligue o leitor na porta USB.
Instala uma vez por computador e exige senha de administrador (regra do Windows). Sem admin, peça ao TI para instalar só o driver. Alguns PCs reconhecem o leitor sozinhos — vale testar o Passo 2 mesmo assim.

Passo 2 · Programa de leitura

  1. Mova a pasta 2-Programa-de-leitura para um lugar fixo, como C:\LeitorDigital. Não precisa instalar.
  2. Dê dois cliques em Abrir-leitor.bat. Se o Windows perguntar, escolha Mais informações e Executar assim mesmo.
  3. Para abrir sozinho ao ligar o Windows, execute uma vez o Abrir-com-o-Windows.bat.
O programa não abre janela — roda em segundo plano. Confira no Passo 3. Não precisa de admin.

Passo 3 · Conferir

  1. Atualize esta página (Ctrl+F5). Deve aparecer "Hamster DX conectado" no canto superior.
  2. Na primeira vez, o navegador pergunta se o site pode acessar a rede local: toque em Permitir.
  3. Se não conectar, abra http://localhost:5000/apiservice/device-unique-id: se mostrar "success":true, o leitor está pronto. Se não, veja o LEIA-ME.
O leitor só funciona no computador onde está ligado. Para fechar o programa, finalize Fingertech-API no Gerenciador de Tarefas.
Leitor não encontrado neste computador Abra o programa Fingertech-API no PC onde o Hamster DX está ligado. O cadastro só funciona nesse computador.
