Instalar o leitor neste computador

O Hamster DX precisa de dois arquivos no computador onde está ligado.

⬇ 1. Driver do leitor ⬇ 2. Programa de leitura
Ver o passo a passo da instalação

Passo 1 · Driver

  1. Baixe o driver e extraia o .zip (botão direito, Extrair tudo).
  2. Abra a pasta UBio_Hamster_X_Driver_Setup_x64 e execute o UBio_Hamster_X_Driver_Setup_x64.exe.
  3. Siga as telas até Concluir e ligue o leitor na porta USB.
Instale uma vez por computador. Se pedir senha de administrador, chame o suporte de TI.

Passo 2 · Programa de leitura

  1. Baixe o programa e extraia o .zip.
  2. Mova a pasta LeitorDigital para um lugar fixo, como C:\LeitorDigital. Não precisa instalar.
  3. Dê dois cliques em Abrir-leitor.bat. Se o Windows perguntar, escolha Mais informações e Executar assim mesmo.
  4. Para abrir sozinho ao ligar o Windows, execute uma vez o Abrir-com-o-Windows.bat.
Se aparecer aviso de firewall, permita o acesso.

Passo 3 · Conferir

  1. Atualize esta página (Ctrl+F5). Deve aparecer "Hamster DX conectado" no canto superior.
  2. Na primeira vez, o navegador pergunta se o site pode acessar a rede local: toque em Permitir.
  3. Se não conectar, confira se o leitor está na USB e se o Abrir-leitor.bat está aberto.
O leitor só funciona no computador onde está ligado. Para fechar o programa, finalize Fingertech-API no Gerenciador de Tarefas.
Leitor não encontrado neste computador Abra o programa Fingertech-API no PC onde o Hamster DX está ligado. O cadastro só funciona nesse computador.
