Backup e Excel

Guarde uma cópia dos dados fora do sistema e exporte as folhas de liberação para uma planilha.

Esta tela é só do Departamento Pessoal.

Proteção extra

Exportar backup dos dados

Gera um arquivo .json com todas as liberações e os colaboradores cadastrados. Guarde em um lugar seguro (pen drive, e-mail, nuvem). Se alguma coisa for apagada por engano, este arquivo recupera.

    Recuperação

    Importar backup dos dados

    Escolha um arquivo de backup. Nada é apagado: o sistema só recoloca o que estiver no arquivo.

    Como restaurar?

    Arquivo

    Exportar as folhas de liberação (PDF ou imagem)

    Gera as folhas iguais à tela "Visualizar liberação", com as assinaturas e o carimbo do RM, para arquivar o mês. Pensado para muitas liberações: tudo é separado por dia.

    Formato
    Como salvar?

    Planilha

    Exportar a tabela de liberações para o Excel

    Uma linha por folha de liberação, com todos os campos da folha (colaborador, função, horário, motivo, abono, assinaturas com data e hora, saída e lançamento no RM). Inclui todas as liberações, mesmo as que estão na lixeira.

    Sem datas, exporta tudo. As datas usam o dia da liberação.
